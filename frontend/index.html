The problem

AI agents are starting to act directly on blockchains. Deterministic smart contracts can enforce arithmetic limits — but they cannot read a natural-language policy, weigh external evidence, or judge whether an agent's stated intent makes sense. And a single centralized AI gatekeeper means whoever controls the model controls the agent.

🧠

Policies humans actually write

"Only infrastructure payments up to 50 USDC. Nothing that looks like gambling." Validators interpret this semantic policy — no Solidity contract can.

🌐

External evidence, verified

Recipient reputation and risk flags are fetched from a content-pinned registry, keccak256-verified on-chain by every validator on every run.

🛡️

LLM judges, contract enforces

Consensus labels the semantics; deterministic gates clamp what the LLM can allow. A fooled model still cannot authorize a limit violation or a flagged target.

Why GenLayer consensus is load-bearing, not decorative

The question this protocol answers: "what must NOT depend on my frontend, my backend, or one centralized AI?" — whether an autonomous agent's action complies with its human-defined policy under current external context. That decision lives inside the Intelligent Contract. The leader proposes a judgment; every validator independently re-fetches the pinned evidence, recomputes the same deterministic facts, re-runs the arbitration, and compares only the substance — the fact set, criterion labels, and evidence hash. The final verdict is derived by contract code from consensus-checked inputs. Money only moves in the deterministic enforcement layer.

Consensus Activity

How GenLayer decides. The leader proposes; validators independently re-verify the substance; the contract derives the verdict.

Leader / Validator Flow

The leader receipt and finalization are real on-chain data. The per-validator grid visualizes the Studionet validator set; unless the receipt exposes per-validator votes, it is labeled DEMO MODE. The consensus result itself — the decision, criteria labels, facts, and evidence hash — is real contract state written by real GenLayer consensus.

Equivalence Principle

Validators do NOT compare free-text reasoning. Each validator independently:

1 · re-fetch pinned registrykeccak verified
2 · recompute deterministic facts9 booleans
3 · re-run LLM judgmentsame prompt
4 · compare substance onlyfacts + labels + hash

A malicious or hallucinating leader whose facts, labels, or evidence hash diverge is rejected by validators. A fooled LLM is still clamped by deterministic gates. Every failure mode — dead fetch, hash mismatch, malformed JSON — escalates; none can approve.
